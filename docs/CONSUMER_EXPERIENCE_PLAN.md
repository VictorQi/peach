## 阶段验收

### 规范与默认行为

- 仓库内规则引用均能取得，不要求维护者私有文件、记忆或未安装命令。
- 启动、刷新、升级、返回页面、网络错误和后台恢复均不打开教程、凭据请求或其他交互程序。
- 用户主动配置的 Cookie、Token、代理继续只用于相应来源；主动连接账号等入口保留，说明实际操作对象。
- 同步、停止读取和可逆标记不重复确认；不可逆删除、外发隐私数据和确有数据损失的动作保留相应保护。
- 来源拒绝、验证、限流和服务器超时分别记录，禁止用换浏览器或弹登录框掩盖失败。

### 后台任务

资料更新定时器只检查已主动开始的一轮；它派发的父任务成功仅表示已入队。`FollowupRunner` 执行实际后继，写账本的后继共用串行通道；任务中心与设置快照按后继的真实状态显示剩余工作。队列控制、请求前停点和重启恢复共用已持久化的暂停、取消意图。每轮固定开始时的媒体与实体范围，新的内容不会使已完成轮次自动重开。

已取得临时账本中的旧队列保留与暂停、未写回执的派发恢复、累计队列上限、固定范围、只重试失败项及取消后重启不再派发的回归证据。实际 HTTP 传输边界用替身请求验证：在途请求退出后确认暂停，下一次请求未发出，取消后保持一次请求。旧版本超量队列的兼容边界见 [运行与配置](OPERATIONS.md#升级后的资料处理)。真实安装发现任务状态逐条读取控制文件导致超时，已按请求共用读取并批量取得后继；相关 97 项回归通过，安装后的真实任务接口已返回。未截断历史返回结果，也未将请求快照的缓存用于后台控制。

- 将本地迁移与可选联网补修分开；用户未启用的联网能力不借升级自动开启。
- 为父任务、后继、重试和恢复建立一致的范围、停止条件及状态表达。
- 用临时账本验证长队列、失败来源、重复启动、暂停和取消；核对实际请求停止，不能只看状态字样。
- 后继尚未完成时明确显示剩余工作；派发成功不能展示为全部完成。

### 首次与日常使用

原位添加按 [ADR-0135](adr/0135-inline-folder-import.md) 实现。已取得合成短片从选择目录、实际入库、同页出现到播放接口成功的桌面与手机证据；自动化中的选择结果替身与真实制品验收分别记录。真实 Windows 制品在独立空数据目录完成路径添加、配置保存、读取与同页出现示例；系统目录窗口由本机操作者现场确认可见。独立服务的配置接续由验收宿主重启，不冒充对完整托盘首启过程的自动化验收。目录校验和任务测试只使用临时目录，未写入本机馆藏。

- 分开验证真正空库、筛选无结果、已有目录但未扫描、正在读取以及目录不可用，避免误判成新用户。
- 首次操作的主路径是“添加文件夹 → 选择 → 开始看到内容”；高级配置可稍后修改。
- 文件选择、默认读取范围和后台处理用途在当前位置说清；不扫描未选择目录，不为减点击而扩大权限。
- 浏览器页面与 Windows 桌面分发共用产品行为；浏览器无法选择远端目录时提供实际可用路径。
- 为首屏建立可重复的测量，记录到首项可操作内容的时间、请求依赖、点击与跨页次数；用同一数据与环境对比改造前后，不虚报性能收益。

日常首屏按 [ADR-0136](adr/0136-catalog-first-content.md) 推进。本机遮挡、主题、排序与版式在打开页面前同步恢复；来源探测、跨设备偏好与人物资料各自读取，不再汇合成主列表的启动门槛。离线只描述播放可用性，不撤掉已编目的浏览范围。新作区已有位置时原位更新，已知为空时晚到的新作留到下次进入显示。

已取得三项可选接口持续挂起、一次真实列表失败后原位重试、卡片显示与首图解码的桌面和手机证据；这一组包含 6 个浏览器用例与 113 项组件检查。单次合成演示样本记录约为桌面 1.60 秒、手机 1.23 秒，包含一次重试，不代表真实馆藏性能或改造前后的提速比例。任务回执按本次观察到的相同任务号判断，初读到的近期终态不自动弹出。

原位添加与首屏组合复查的 8 个浏览器用例已通过；追加媒体的用例最后单独执行，避免共享演示库的写入影响其他布局与计数检查。读取真实新增短片、详情实际显示和返回后所浏览条目保持均已核对，仍未以此替代安装制品验收。
