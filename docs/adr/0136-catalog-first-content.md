# ADR-0136：馆藏内容优先显示

- 状态：已接受
- 日期：2026-11-05
- 关联：[消费者行为边界](0134-consumer-control-and-privacy.md)、[前端分层](0031-frontend-react-boardui-tailwind.md)

## 决策

主列表按地址与已同步恢复的本机偏好立即读取，不等待来源探测、跨设备偏好或人物形状名单。本机的画面遮挡、主题、排序和版式仍在页面打开前恢复。可选请求失败不撤掉已取得内容，也不阻止打开详情；主列表读取失败沿用原位重试。

默认浏览范围包含离线来源的已编目内容，来源状态只用于可用性说明与播放错误，不在晚到时改写筛选。地址明确选择的来源和空范围继续有效，不为加速持久保存另一份敏感馆藏缓存。

主列表第一张媒体画面使用立即加载与高优先级，其余图片沿用浏览器延迟加载。画面大小和原位换取景继续复用已有组件，不因调整版式替换同一张图片。

打开页面初读到的任务完成或失败，即使发生在两分钟内，也保留在任务中心，不自动弹出回执或历史失败卡。本次观察到同一任务运行到终态时仍正常给出回执，主动展开的任务状态继续可用。

新作区沿用本机保存的有无状态留位；还没有记录时保留既有的占位行为，不为确认有无而阻塞馆藏。已知为空的一次进入中，晚到的新作只更新下次显示状态，不从当前卡片上方插入。下一次进入目录可使用已取得的新作结果。人物形状名单更新不直接重排正在看的首页。

## 验收

桌面与手机浏览器挂起来源、偏好、人物名单与新作请求，验证真实馆藏仍可显示、原位重试和打开详情。验证本机遮挡、所选排序、首图加载属性与图片解码；放行可选请求后检查卡片位置，并保留原有新作封面取景和导航回归。

测量以真实卡片和图片就绪为准，注明是否包含重试以及挂起的请求；同一环境取得改造前后样本前，不声明提速比例。源码与合成演示数据的验证不代替安装后的首屏核验。
