# ADR-0131：消费者控制、易用性与隐私边界

- 状态：已接受
- 日期：2026-11-04

## 背景

Peach 面向不同技术背景的消费者。自托管和开源不意味着使用者理解采集协议、凭据或后台任务，也不意味着应用可以自行操作其他软件。教程遮罩、后台浏览器窗口、反复请求凭据和常驻升级横幅会打断正在进行的事情，并使用户无法判断应用是否仍在其控制之下。

本 Fork 的产品决策由当前维护者确定。上游实现、个人环境和历史偏好作为参考；与本决策冲突的默认行为须按本决策评审。本决策约束 ADR-0065 的浏览器传输使用边界，以及教程、更新和后台补全的交互方式；独立浏览器配置目录等隔离措施不能替代用户主动操作。

## 决策

### 可直接上手的基础体验

基础能力使用合理默认值、清楚的动作和原位反馈，不要求先读教程、懂技术词汇或配置外部账号。高级配置按需要提供，不作为进入应用或使用无关能力的前置条件。可选能力缺失时跳过受限部分；已取得的本地资料与公开结果仍然可用。

教程和帮助只由用户主动打开。关闭、跳过或完成后不自动打开另一段教程，不因刷新、返回页面或普通升级恢复遮罩。软件版本、更新进度与安装操作放在设置页，不在浏览和播放页面常驻催更。

首次空页面直接提供当前可执行的核心动作。例如添加本地内容应从内容区选择文件夹、开始读取，并在同一位置逐步显示结果；名称、外观和高级来源使用合理默认值，稍后可改。不把打开教程、跳转设置、填完高级表单和返回首页当作添加第一份内容的必要路径。远程浏览器不能选择服务端文件夹时，应明确对象并提供可用的原位输入，不能弹出另一台机器的窗口。

已有内容的用户打开后优先看到可浏览的馆藏，保留页面位置和必要的浏览状态。首屏数据、可选统计、后台状态和资料补全分别推进；无关请求慢或失败不得阻止内容显示。封面未取得时保留卡片尺寸与可操作的文字，首屏图片优先于屏外图片和后台补全。缓存遵守当前权限、数据来源和失效边界，不默认把敏感馆藏另存到持久浏览器存储。

验收分别覆盖空库、已有内容、首次读取进行中、配置已存在但目录不可用、筛选无结果和请求失败。空库判断不能只依据当前页没有命中。记录到第一项可操作内容的时间、完成首个动作的点击与跨页次数，以及结果出现时是否抢焦点或移动已有内容；骨架出现时间不能替代内容可用时间。

### 配置就是有明确范围的主动选择

用户在现有配置入口了解用途并启用能力、填写对应 Cookie 或 Token 后，可在该范围内持续工作，无需再弹授权确认。未配置凭据时不弹窗索要、不要求普通用户学习如何提取凭据；失效状态留在来源配置或相关任务中，不反复催促。

授权范围包含用途、处理的数据、访问对象和持续方式。填写一个来源的凭据不授予访问其他账号、读取浏览器历史或向其他服务发送数据的权限。用途、接收方或数据范围扩大时先调整配置说明和选择机制；不能沿用旧配置推定新授权。

### 后台执行不接管桌面

后台采集、升级补修和重试不启动或操纵 Chrome、Edge 或其他交互应用，不导航用户页面、不抢焦点。站点拒绝访问、验证页、限流和连接失败按来源记录并停止或冷却；站点故障不转化为登录请求。

用户主动点击的账号连接、外部播放或文件选择可以调用相应程序，入口须明确说明动作。执行本地媒体处理所需的非交互子进程遵循已启用能力及任务范围；不把它扩展成交互式桌面自动化。

### 后台工作有范围和终点

用户能在现有任务中心看到触发原因、处理范围、实际进度和结果，并暂停或取消。主任务与后继分别完成时，文案说明仍在运行的工作，不以派发成功表示全部处理完成。

子任务、重试、升级与重启恢复继承有效的配置和停止意图。自动恢复不扩大范围；可选联网补全不借必要的本地数据迁移自动启用。调度限制同时考虑整轮任务规模与资源预算，单批入队上限不作为整轮上限。

### 弹层只服务于当前动作

先使用设置、表单旁状态、来源记录或任务中心。后台困难不强迫用户当场作答，也不新增授权弹窗来补偿不合理默认值。

| 场景 | 交互 |
| --- | --- |
| 教程邀请、版本推荐、缺少可选凭据 | 不自动弹出；入口和状态留在对应页面 |
| 用户点击同步、切换可逆设置或停止读取 | 直接执行并给出原位结果；已有设置决定范围 |
| 用户主动配置高级来源或连接账号 | 在该入口说明用途，按选择执行，不重复确认相同范围 |
| 用户主动删除不可恢复的数据、卸载或中断不可续跑工作 | 说明实际损失和范围，必要时在操作前确认 |
| 后台验证、限流、断网或权限不足 | 独立记录并降级，保留其他能力，不打开其他应用 |
| 诊断报告、历史或其他隐私数据外发 | 明确接收方、数据与用途，由用户主动选择；未选择不外发 |

### 隐私从默认行为落实

默认只处理实现已启用用途所需的数据，限制保存范围、保留期限和接收方。浏览历史、观看记录、馆藏与搜索信息按高隐私影响处理；技术上的 Cookie、Token 和路径也可能泄露身份、偏好或设备信息。

可选联网、遥测、诊断上传和账号接入有清楚说明与便捷关闭方式。关闭后停止后续工作和自动恢复，保留用户资料；确需清理的数据说明对象与后果。日志与公开材料不包含凭据、个人绝对路径、馆藏明细或未脱敏诊断内容。

## 评审与验收

每次涉及启动、配置、后台调度、外部程序或用户数据的改动，复核：未配置、明确关闭、凭据失效、网络失败、取消、重启恢复以及已有配置升级。自动化回归验证无额外浏览器启动、无自动教程和无越界恢复；布局与可上手性由实际页面验收，不用文件存在或声明替代行为证据。

规则和命令应能从当前仓库取得。不存在的个人技能、命令和本机路径不作为工作前置条件；组件与验证使用仓库内维护的入口。修改规范不代表所有既有实现已经完成验收。

## 放弃方案

- 把浏览器移到屏幕外或换成无头浏览器：没有解决未经用户主动操作就调用浏览器的问题。
- 通过通用弹窗获取一揽子同意：用户无法理解范围，重复打扰也无法形成清楚选择。
- 要求用户完成教程或配置所有来源：把高级能力的成本加给只需要基础功能的人。
- 只隐藏消息而继续原有后台行为：可见程度降低，用户控制权没有改善。

## 后果

部分站点在没有可用凭据或公开接口时不再自动取得资料。已有本地结果和其他来源继续可用，高级用户仍可从明确入口配置所需能力。实现、回归和公开文档围绕同一行为边界维护；上游同类代码引入时也须重新检查。
