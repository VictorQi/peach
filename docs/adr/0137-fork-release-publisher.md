# ADR-0137：Fork 的发布与更新归属

- 状态：已接受
- 日期：2026-11-05
- 关联：[消费者边界](0134-consumer-control-and-privacy.md)、[macOS 应用内更新](0130-macos-sparkle-in-app-update.md)

## 决策

本 Fork 的发布归 `VictorQi/peach`。应用检查、下载链接和安装器工具下载使用该仓库，不因 GitHub 失败转向上游镜像。发布元数据中的外部下载 URL 不作为可信目标，按本仓库、版本和预期文件名构造地址；下载仍须通过原有大小与摘要校验。

检查缓存和准备好的更新事务绑定发布方。旧缓存或旧暂存包未标明发布方，或属于另一发布方时，不继续提供安装；保留原记录、文件与用户数据，用户可在设置页重新检查下载。首次切换到 Fork 使用完整安装包覆盖安装，不把旧上游更新器当作 Fork 发现渠道。

Fork 不持有上游的 Sparkle 签名私钥，不能沿用上游公钥和 feed。`PUBLIC_ED_KEY` 当前为空，macOS 使用本 Fork 的 DMG 下载入口；拥有自己的签名与经过验收的 feed 后再启用 Sparkle。此决策取代 ADR-0130 中公钥不可清空的限制，不生成或操作任何真实密钥。

Windows 安装保留数据目录及用户已保存的诊断、馆藏分享和凭据选择。接收端未配置的诊断与分享能力不发送，不把部署遥测服务作为使用基本功能或构建安装包的前提。

## 验收

临时更新事务验证上游与未标明来源的包无法替换程序或账本，Fork 自身的下载、校验、失败回退与任务保存仍可用。发布前核对仓库、制品、摘要及更新链接；仅源码验证不能证明覆盖安装成功。
