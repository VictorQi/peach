# ADR-0135：原位添加文件夹与目录热生效

- 状态：已接受
- 日期：2026-11-05
- 关联：[消费者行为边界](0134-consumer-control-and-privacy.md)、[任务后继](0040-tasks-declare-followups-at-the-end.md)

## 决策

空馆藏提供立即可操作的添加入口。桌面用户主动点击后选择系统文件夹，取消不改变配置；无桌面的部署填写 Peach 服务器上的实际目录。读取失败留在当前位置重试，已有内容继续可浏览。筛选无结果保留清除筛选入口，不当作空馆藏。

新建媒体库默认只使用本地资料和预览；添加到当前所选媒体库时保留该库已有的身份、处理方式和其他设置。配置写入复用现有目录校验、持久身份、备份和原子替换。目录加入后更新媒体授权根、来源探测与本地监视，不重启整个服务；发现队列和已经开始的任务不被清空。

每次读取固定到用户选择的存储根，复用 `FollowupRunner` 的写入通道、任务中心、请求停点和检查点。读取和预览仍使用现有全库处理锁；其他任务占用时有序等待。入队仅表示开始安排，界面按实际任务状态显示进度；部分文件失败保留失败状态与已取得内容。后续配置移除该根时，不把原任务扩大到其他来源。

增量调度在共享处理锁被占用时不再启动另一轮全局任务。同一批文件由当前读取负责结算，避免重复处理和任务浮窗。取消目录读取或明确范围的主任务时，同时撤回对应的待处理版本，保留已取得内容和取消记录；之后发生的新文件版本仍可按既有配置处理。重启保留未取消任务的检查点。

普通首次安装以选择视频文件夹为主操作，使用本地资料和仅本机访问的默认值；也可暂不添加或主动进入其他设置、接回已有数据。首次建立数据库后的服务接续沿用分发入口，准备好后在同一窗口进入馆藏。已配置实例添加文件夹不走整套首次设置、教程或全服务重启。

## 边界与验收

添加接口沿用应用鉴权、本机管理与同源写入边界，只在可写实例启用。远程浏览者不取得本机目录管理信息；无桌面的服务器不弹出宿主机系统选择窗口。目录加入不改变端口、访问密码、凭据、复制角色或用户记录；这些配置继续由各自入口管理。

临时账本验证身份和处理方式保留、目录范围、重复点击、取消及重启检查点。浏览器验证桌面与手机尺寸下的原位添加、可用播放链和无额外对话框；首次安装器接续与真实升级另在制品验收中核对。首次布局验收使用空库或合成媒体，不把合成测试页宣称为真实馆藏预览。
