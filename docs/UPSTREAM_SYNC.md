## 首屏性能取证

在本批前端生效后，用 Edge 打开馆藏页并附加 `measure=1` 查询参数。取证最多持续 60 秒，结果位于当前页面的 `#peach-performance` 输出节点，页面关闭后即丢弃；不发送报告、不写浏览器存储、不记录作品名、资产编号、查询参数或凭据。

- `firstCardReadyMs`：首个可见卡片的文字与按钮 DOM 就绪；不代替实际点击验收。
- `firstCoverDecodedMs`：该卡片图片解码成功；失败或尚未完成为 null，另记错误次数。
- `resources`：限定同源端点的起始时间、总耗时、首字节时间和大小，最多 250 项。
- `paints`、`longTasks`：绘制与主线程长任务；先检查 `observedTypes`，不能把浏览器未支持的类型当成零耗时。

时间相对当前导航开始；读缓存与冷启动须分组记录，不能混算。后端真实服务测量和账本副本分析单独记录构建身份，副本返回内容可用摘要比较等价，不在报告保存原始馆藏。

后续顺序：完成剩余首屏差异与性能取证 → 固定交付提交 → preflight 与 full → 本机实际新版本及 Edge 验收 → 推送 Fork PR 并经 ready/integrate 合入。运行报告仅存本机，不在公开文档记录馆藏内容、凭据或设备坐标。
